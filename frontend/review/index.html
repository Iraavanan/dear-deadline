Why check the wording?

Social Security’s inspector general found a policy deficiency in 46% of the Title II overpayment notices it reviewed for fiscal 2023. The audit identified missing explanations and missing information about review rights. The agency’s instructions describe the contents expected in an initial notice. Read the audit · Read SSA’s instructions.

Reproduce or reuse the work

Download the kit and run node score.js --verify in the extracted directory. The code, inputs, annotated answers, agency sources, version, file hashes and recorded results travel together. The same checker runs in the app.

The five measured elements are the cause, affected period, calculation, reconsideration and waiver. A matched passage still needs the reader’s confirmation. A missing scan page can hide an answer. The project has measured performance on these examples only. Independent replication, real-world accuracy, usage and claimant outcomes are separate evidence.
